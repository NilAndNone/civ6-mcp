# Development Docs

Docs in this directory support repository development, design, and acceptance.
Installed-plugin usage lives under `plugin/`.

## Current Runtime Source

- `current-architecture.md`: current architecture and development mainline.
- `plugin-architecture.md`: plugin/module layering.
- `codex-hl-observation.md`: live strict evidence and run notes.
- Strategy, Review, Validation, and Governance module docs for their respective
  offline workflows.

HTML files are non-authoritative generated/human views. Runtime entrypoints are
defined by `plugin/commands/*.md` and active strategy assets, not by HTML.

## Historical Or Reference Only

- `live_refactor/`
- `codex_hl_civ6_live_refactor_pack/`
- `history/`

Historical/reference material may explain old decisions, but it cannot define
current runtime commands.
