## Summary

Sacred Path is a pantheon in Civilization VI. It increases the Faith output of Holy Site districts by 1 for each adjacent Rainforest tile.

## Key Facts

- Name: Sacred Path
- effect: Holy Site districts get +1 Faith from adjacent Rainforest tiles.
