## Summary

Cheating, in its broadest sense, refers to any action that allows a player to win undeservedly. Individual players (and their human opponents, in multiplayer games) decide what constitutes cheating, as per the following examples:
* Some players consider it cheating to reload a previous save file (so as to make better decisions) while others consider it perfectly valid. Civilization VI and its expansions don't have "Ironman Mode" like some other games do, so whether and to what extent this behavior is acceptable is up to the player.
* Using cheats can allow players to fix high-impact mistakes and avoid restarting a game in which they've already invested several hours.
* Using cheats can give players an edge when playing on a higher difficulty level than they normally do.
While each individual player decides where to draw the line when it comes to cheating, some cheats are trivial and others make the game virtually impossible to lose. There are also mods that make the game easier to win.
Finally, there are some in-game exploits, or methods of abusing features in the unaltered game. Errors and shortcomings in the AI's reasoning can easily be argued as unintended by the developers. While not strictly cheating, as it is not listed by the developers, some see this manipulation of the game's faults as a similar issue, with patches being introduced to correct code and prevent exploits when discovered.
