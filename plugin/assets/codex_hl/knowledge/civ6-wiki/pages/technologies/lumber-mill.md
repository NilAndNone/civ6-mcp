# Lumber Mill

- Category: technologies
- Source: [https://civilization.fandom.com/wiki/Lumber_Mill_%28Civ6%29](https://civilization.fandom.com/wiki/Lumber_Mill_%28Civ6%29)
- Aliases: Lumber Mill

## Summary

The Lumber Mill is a standard tile improvement in Civilization VI. It can be built only on tiles with Woods.
In the Gathering Storm expansion, the Lumber Mill is unlocked with Construction and can be built on tiles with Rainforests after researching Mercantilism.

## Key Facts

- req: Machinery
- Plunder yield: Gold
- effect: +1 (+2 ) Production; +1 Production Steel; +1 Production if adjacent to a River (Vanilla and only); +1 Production Cybernetics
- terrain: Woods, Rainforest
