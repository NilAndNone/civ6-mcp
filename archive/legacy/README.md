# Legacy Archive

This directory keeps assets that are no longer part of the active `codex-hl-civ6` plugin path.

Archived content includes:

- old CivBench evals and saves
- old web/Convex dashboard
- old scripts and publish tooling
- old devlogs, research docs, generic MCP docs, and Hotseat docs
- old client config examples

Do not import or route active plugin code through this directory. Move material back into the active path only with explicit approval.
